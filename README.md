# 📺 MovieBox TV

A lightweight, remote-first Android TV app for streaming, built with a Rust core.

> ⚠️ **Vibe-coded project.** This app was made with AI assistance ("vibe coding") and is **based on the original [MovieBox-Tui](https://github.com/mesamirh/MovieBox-Tui) by [mesamirh](https://github.com/mesamirh)**. All credit for the original idea and code goes to the original creator. Expect rough edges and bugs.

---

## ✨ Features

- Fully controllable with the TV remote (Up / Down / Left / Right / OK / Back)
- Press Back again to exit
- High-contrast focus highlights, easy to see from the couch
- Stremio-compatible addon support
- Favorites
- Choose an external player (mpv, Nova, etc.)
- Low memory use, made for TV boxes with 1.5–2 GB RAM

## 📥 Install

1. Go to the [**Releases**](../../releases/latest) page.
2. Download the latest `.apk` file.
3. Copy it to your TV (USB drive, or download it directly on the TV).
4. On your TV, allow **Install unknown apps** for your file manager or browser.
5. Open the APK and install it.

## 🚀 First use

1. Open the app.
2. Go to **Settings** and add your addons.
3. Pick your preferred player.
4. Search or browse and enjoy.

## 🛠️ How it's built

Every time the source is updated in this repo, GitHub Actions builds the Rust core and the Android TV app automatically, then publishes a new APK in Releases.

## 🐞 Known issues

- Some addons or streams may not work on every device.
- Posters may be blurry on some TVs.
- This is a hobby project and is not guaranteed to be stable.
